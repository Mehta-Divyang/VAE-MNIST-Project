# Variational Autoencoder (VAE) on MNIST

This project implements a Convolutional Variational Autoencoder (VAE) for image reconstruction and generation using the MNIST dataset.

##  Features
- Image Reconstruction
- New Digit Generation
- 2D Latent Space Visualization
- Latent Space Traversal

##  Tech Stack
- Python
- TensorFlow / Keras
- NumPy
- Matplotlib

##  Results
- Good reconstruction quality
- Smooth and meaningful latent space
- Realistic generated digits

##  Dataset
MNIST dataset (via TensorFlow)
